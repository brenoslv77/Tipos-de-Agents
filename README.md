Tipos de Agents
Repositório dedicado aos meus estudos de Inteligência Artificial, ao curso Fundamentos de IA com AWS e ao desenvolvimento gradual de agentes com diferentes habilidades e níveis de integração.
Objetivos
- Registrar aprendizados e experimentos durante os estudos de IA e AWS.
- Desenvolver agentes em etapas, começando por conceitos básicos e avançando para integrações mais completas.
- Documentar o funcionamento, as tecnologias, as limitações e as melhorias de cada projeto.
- Manter os projetos organizados para facilitar a evolução e a consulta futura.
Estrutura do repositório
Pasta/arquivo	Finalidade
agent-basico/	Chatbot inicial desenvolvido com HTML, CSS e JavaScript, com respostas baseadas em regras.
agent-avancado/	Espaço planejado para um agente com interação com elementos e dispositivos simulados na página.
agent-aws/	Espaço planejado para experimentos com agentes e serviços de IA da AWS.
habilidade-automacao/	Instruções de uma habilidade voltada a perguntas sobre automação residencial. Consulte o SKILL.md dessa pasta.


Algumas pastas são planejadas e podem ainda não conter um projeto. A estrutura será atualizada conforme o desenvolvimento avançar.

Habilidade de automação residencial
A pasta habilidade-automacao/ contém um arquivo SKILL.md com orientações para um agente responder em português brasileiro sobre temas como iluminação, climatização, cortinas, controle por voz, benefícios da automação, redes mesh, orçamentos e instalação.

O arquivo também orienta o agente a não inventar preços, especificações técnicas ou serviços quando não houver informações suficientes.

Esse arquivo é um conjunto de instruções; sozinho, não implementa uma integração com a AWS nem executa funções. Seu uso dependerá do agente ou da ferramenta com que for integrado futuramente.
Tecnologias e serviços
As tecnologias variam conforme cada projeto. O agent-basico, por exemplo, utiliza:
- HTML5
- CSS3
- JavaScript
Integrações com serviços da AWS serão documentadas nas pastas correspondentes quando forem implementadas.
Como explorar
1. Entre na pasta do projeto que deseja conhecer.
2. Leia o README.md específico, quando disponível.
3. Siga as instruções daquele projeto para executá-lo.
4. Consulte as limitações e melhorias planejadas antes de considerar uma funcionalidade como implementada.
